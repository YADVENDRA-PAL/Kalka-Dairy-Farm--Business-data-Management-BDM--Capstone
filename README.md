# Data-Driven Insights for Kalka Dairy Farm

## BDM Capstone Project

This project focuses on analysing business data from Kalka Dairy Farm, located in Ingohata, Hamirpur, Uttar Pradesh.

The project uses data from January to June 2025 to analyse milk production, sales, customers, feed consumption, veterinary records, expenses and profitability.

## Objectives

- Organize and manage dairy farm business data
- Analyse milk production and sales trends
- Analyse feed consumption and expenses
- Study customer and sales patterns
- Analyse profitability and key business indicators
- Generate data-driven insights and recommendations

## Dataset

The project contains data related to:

- Animal Master
- Daily Milk Production
- Customers
- Milk Sales
- Feed Consumption
- Veterinary Records
- Expenses
- Monthly Summary
- KPI and Dashboard Data

## Tools & Technologies

## Analysis Performed

- Descriptive Statistics
- Production Trend Analysis
- Sales Analysis
- Customer Analysis
- Cost and Profitability Analysis
- KPI Analysis
- Data Visualization
- Business Insights and Recommendations

## Project Period

January 2025 – June 2025

## Key Business Areas

The analysis focuses on milk production, revenue, expenses, feed consumption, customer sales and overall profitability.

## Project Outcome

The project converts raw dairy-farm records into structured business information and analytical insights that can support better data management, performance monitoring and business decision-making.
